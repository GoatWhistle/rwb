# Название и логотип решения

## Выбор: **Tally**

«The figures tally» — цифры сходятся; *a tally* — накопительный счёт, бирка с зарубками,
по которой две стороны сверяли долг. Одно слово держит обе идеи решения: 28 самопроверок
сходимости и одна цифра для всех аналитиков. Два слога, в русской речи — «тэ́лли»
(«посмотри в Tally», «в Tally сходится»), склоняется без усилий, не путается с русскими словами.
Риск — Tally ERP (Индия, учёт) и Tally Forms (конструктор форм): ниши другие,
для внутреннего инструмента модели данных маркетплейса конфликт не критичен.

Русскоязычный предшественник — «Свод» (свести цифры / свод данных / несущий свод raw → core → mart); заменён требованием латинского имени.

## Альтернативы

| Название | Смысл | Риски |
|---|---|---|
| **Plumb** | отвес: эталонная вертикаль, «out of plumb» = расхождение | в речи «плам» = слива; без пояснения смысл не считывается |
| **Keel** | киль: несущая основа, на которой стоит вся модель | «кил» → kill; о сходимости цифр не говорит |
| **Ledger** | книга учёта, одна запись на всех | занято (Ledger — крипто-кошельки), ассоциация с блокчейном |
| **Even** | «цифры ровно», баланс в ноль | общее слово, плохо ищется, «ивен» в речи теряется |
| **Tie-out** | бух. термин «сверка до первички» | дефис, двухсложное, понятно только финансистам |

## Таглайны

- «Одна цифра для всех».
- «Цифры сходятся. Каждый раз».
- «От корзины до выкупа — одной моделью».
- «Собирается с нуля. Сходится до копейки».
- Питч: «Tally — модель данных маркетплейса, в которой цифры сходятся сами».

## Логотип

Геометрия повторяет логотип RWB: моноширинный штрих одной толщины, скругления одного
радиуса, плоские срезы, плотная разрядка. Знак — открытая скобка (зеркальная чаша «R» и «b» RWB),
держащая одну цифру (квадрат).

| Параметр | Значение |
|---|---|
| Сетка вордмарка | x-высота 20 ед. (y 6…26), выносные t/l до y 0, нижний выносной y до 32; viewBox `0 0 85 32` |
| Штрих | 4 ед., `stroke-linecap: butt`, `stroke-linejoin: miter` |
| Скругление | радиус 3 по осевой (внешний 5, внутренний 1) |
| Ширины букв | t 14, a 22, l 4, y 22 |
| Разрядка | t→a 4, a→l 5, l→l 5, l→y 5 |
| Знак | поле 32×32: скобка по осевой x 6…28, y 6…26, квадрат 6×6 (rx 1) в 14,13 |
| Локап | знак 32 + зазор 10 + вордмарк 85 = `0 0 127 32`; x-высота вордмарка совпадает с осевыми скобки (y 6…26) |
| Чёрный | `#1D1D1B` |
| Знак в цвете | штрих: градиент 135° `#3FAEFD → #2068F5`, квадрат `#8356EE` |
| Фон обложки | 90° `#2348FF` 0–30% → `#78E9FF` 100%, логотип `#FFFFFF` |
| Фавикон | плашка 32×32 rx 7, градиент 135° `#2348FF → #3FAEFD`, белые скобка и квадрат 8×8 |

### Правила использования

- **Охранное поле** — одна x-высота (20 ед.) со всех сторон; для знака — 16 ед.
- **Минимальный размер**: вордмарк — от 20 px в высоту (x-высота ≈ 12 px); локап — от 96 px в ширину; знак — 24 px; ниже — только `favicon.svg` (16 и 32 px).
- **Фоны**: белый, `#F1F1F3`, `#F0E4FF` — цветная или чёрная версия; градиенты — только белая.
- **Нельзя**: набирать вордмарк шрифтом; менять толщину штриха или радиус; растягивать, наклонять, менять разрядку; заливать вордмарк градиентом; класть цветной знак на синий градиент; добавлять обводку, тень, 3D; менять квадрат на круг или ставить в него цифру; писать имя капсом (TALLY) или кириллицей в логотипе.
- В тексте и заголовках имя набирается: «Как устроен *Tally*» — Inter Bold + PT Serif Italic `#328EF9`.
