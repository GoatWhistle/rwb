Правила переноса в core

raw: всё text core: типы, ключи, правила

Типы на входе

::timestamp, ::numeric

мусор валит сборку, а не прячется в отчёте

Пустое это NULL

NULLIF(trim(x), '')

пустая строка из CSV значит «данных нет»

Ключи и связи

PRIMARY KEY, REFERENCES

позиция с несуществующим товаром не запишется

CHECK-правила

score BETWEEN 1 AND 5

статус из списка, цена от нуля, оценка 1–5

Дедупликация

DISTINCT ON (unique_id)

один человек это одна строка

Пересборка с нуля

DROP SCHEMA; BEGIN … COMMIT

наполовину собранной модели не бывает

Один скрипт build_core.sql собирает модель на чистой базе целиком, сколько угодно раз.
