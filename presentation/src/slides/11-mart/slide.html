Витрины mart: один SELECT

order_fulfillment1 строка = 1 заказ
  • этапы в днях: подтверждение, продавец, перевозчик
  • on_time вручён не позже обещанного
  • суммы позиций, доставка, последний отзыв
  • нарушенная хронология в NULL, медианы не портятся
seller_shipment1 строка = заказ × продавец
  • срок отгрузки пары: максимум по её позициям
  • shipped_on_time успел ли продавец
  • is_single_seller: рейтинг честен только для одиночных

Зачем: вопрос «как исполняется заказ» это один SELECT без join. Ошибиться уровнем и посчитать заказ трижды нельзя.
