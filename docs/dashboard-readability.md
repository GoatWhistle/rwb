# Читаемость дашборда Datum: правила и план исправлений

Контекст: аналитика заказов маркетплейса (выручка, заказы, средний чек, доставка в срок, категории, штаты, продавцы, отзывы). Вкладки: Обзор / Продажи / Доставка / Покупатели. Справа чат примерно на 30 % ширины, поэтому рабочая ширина дашборда около 900–1100 px.

## (a) Правила

1. **Один экран отвечает на 3–5 вопросов, не больше 5–9 виджетов на вкладку.** Дашборд нужен, чтобы понять ситуацию с одного взгляда, а не для свободного исследования. Детали открываются по запросу. [NN/g][nng-pre], [Carbon][carbon]
2. **Самое важное располагается слева вверху и крупнее остального, порядок чтения F-образный.** Пользователь сканирует экран сверху вниз и слева направо. [Carbon][carbon]
3. **Наверху ряд из 4 KPI, ниже один главный график на всю ширину, ниже детали в 2 колонки.** Так получается иерархия «итог → динамика → разбивка». [Carbon][carbon], [Few][few]
4. **В каждой KPI-плитке есть сравнение: Δ к прошлому периоду со знаком, стрелкой и цветом.** Без контекста число ничего не говорит. По IBCS сравнение факта с прошлым периодом обязательно. [IBCS][ibcs], [Few][few]
5. **Цветом разницы показывается смысл, а не направление.** Зелёный значит «хорошо», красный «плохо». Если метрику лучше уменьшать (срок доставки, доля опозданий), рост красим красным. Цвет всегда дублируется знаком или стрелкой. [IBCS][ibcs], [NN/g][nng-pre]
6. **Динамику показываем линией, время идёт по горизонтали.** Для трендов линия читается лучше всего. [NN/g charts][nng-charts], [IBCS][ibcs]
7. **Категории (категории товаров, штаты, продавцы) показываем горизонтальными барами, отсортированными по убыванию.** Длина бара сравнивается точнее всего, длинные подписи не приходится поворачивать. [NN/g charts][nng-charts]
8. **Pie, donut, gauge, 3D и stacked-бары не используем.** Углы и площади читаются плохо. Для «цель против факта» берём bullet chart. [NN/g][nng-pre], [NN/g charts][nng-charts]
9. **Двойные оси не используем.** Два ряда с разными единицами разносим на два small multiples с общей осью X. [Datawrapper][dw-text], [Few][few]
10. **Подписи ставим прямо на данные, без легенды.** Значение пишем у конца бара, имя ряда у конца линии. Легенда заставляет глаз ходить туда-обратно. [Datawrapper text][dw-text], [SWD][swd]
11. **Заголовок графика формулируется как вывод или вопрос, единицы указаны в подзаголовке.** Пример: «Выручка растёт до ноя 2017, затем плато», подзаголовок «млн R$, по месяцам». [Datawrapper text][dw-text]
12. **Числа форматируются одинаково во всём дашборде.** Пробел как разделитель тысяч (`13 245`), компактная запись в KPI (`13,2 млн`), в процентах 1 знак, в рублях и R$ на графиках 0 знаков, в таблицах полные значения. На одной оси одинаковое число знаков. [Datawrapper text][dw-text]
13. **Все числа выводятся моноширинными цифрами (`font-variant-numeric: tabular-nums`) и в таблицах выравниваются по правому краю.** Разряды стоят друг под другом, и значения сравниваются по вертикали. [NN/g tables][nng-tables]
14. **Акцентный цвет один, контекст рисуется серым, семантические цвета (зелёный, красный, жёлтый) только для статуса.** Все бары категорий одного цвета. Выделяется акцентом максимум один элемент. [Datawrapper colors][dw-colors]
15. **Один показатель везде одного цвета.** Если выручка синяя, она синяя на всех вкладках и в чате. [Carbon][carbon], [Datawrapper colors][dw-colors]
16. **Убираем лишнее: рамки панелей не нужны, если есть фон, сетка только горизонтальная и светлая (3–4 линии), оси без засечек, маркеры только на hover.** Чем меньше «не-данных» на экране, тем легче читать. [SWD][swd], [Tufte][tufte]
17. **Текст не мельче 12 px, на графике не больше 2 размеров шрифта, подписи не поворачиваем.** Мелкий светло-серый текст на 9–10 px не читается. [Datawrapper text][dw-text]
18. **Аномалии подписываются прямо на графике.** Пустой ноябрь 2016 (`нет данных`), всплеск Black Friday в ноябре 2017, неполный последний месяц (штрихом). Читатель не должен сам гадать, почему провал. [Carbon][carbon], [Datawrapper text][dw-text]
19. **Неполный период выделяется визуально:** пунктирный хвост линии или полупрозрачный бар с пометкой «неполный месяц». Иначе в конце графика виден ложный «обвал». [IBCS][ibcs]
20. **Фильтр периода и режим сравнения стоят в одной строке над KPI, активные фильтры видны как чипы.** Пользователь всегда знает, на что смотрит. [NN/g tables][nng-tables], [Carbon][carbon]
21. **В таблице 5–10 строк по умолчанию, шапка закреплена, строки разделены тонкой линией или зеброй, есть hover, первая колонка человекочитаемая (не хеш ID).** Так проще держать строку взглядом. [NN/g tables][nng-tables]
22. **Пустое состояние, загрузка и ошибка показываются внутри своей карточки:** скелетон в форме будущего графика, «Нет данных за период» с подсказкой. Весь экран целиком не скрываем. [Carbon][carbon]
23. **Отступы кратны 8 (8/16/24/32), между группами больше, чем внутри группы.** Без разделителей близость сама показывает, что к чему относится. [Carbon][carbon]

## (b) Раскладка по вкладкам (ширина около 1000 px, 12 колонок, gap 16)

Общая шапка всех вкладок:

```
[Обзор | Продажи | Доставка | Покупатели]
[Период: сен 2016 – авг 2018 ▾] [Сравнить с: пред. период ▾] [Штат ▾]   чипы активных фильтров
```

### Обзор: «Как идёт бизнес в целом?»

```

│ 13,2 млн R$   ││ 99 441        ││ 91,9 %         ││ 4,09 / 5       │
│ ▲ 12,4 % ⌒⌒⌒ ││ ▲ 9,1 % ⌒⌒⌒  ││ ▼ 1,2 п.п. ⌒⌒ ││ ▼ 0,05  ⌒⌒⌒   │
└───────────────┘└───────────────┘└────────────────┘└────────────────┘
┌ Выручка по месяцам растёт, пик в ноя 2017 (Black Friday) ──────────┐
│  линия, 1 серия, подписи: максимум и последний месяц;              │
```

## (c) Спецификации (Inter, шрифт дизайн-системы)

### KPI-плитка

```
┌──────────────────────────────┐  padding 16/20, radius 12, фон #fff, без тени
│ Выручка                   ?  │  label: 13 px, 500, #5B5B66, sentence case
│ 13,2 млн R$                  │  value: 28–32 px, Inter 700, tabular-nums, letter-spacing -0.02em, #1D1D1B
│ ▲ 12,4 %  к пред. периоду ⌒⌒ │  delta: 13 px 600, цвет по смыслу + стрелка; «к пред. периоду» 12 px #6B6B76
└──────────────────────────────┘  sparkline: 80×24, stroke 1.5, серый #B8B8C2, последняя точка акцентом
```

- Единица идёт после числа и мельче: `13,2 млн R$` (единица 16–18 px, 500).
- Δ: `▲ 12,4 %` / `▼ 1,2 п.п.`. Для процентных метрик пишем п.п., для остальных %. Нет данных для сравнения: `— нет базы`.
- Пояснение («только доставленные») уходит в tooltip у «?», а не текстом на 9 px.
- Высота плиток в ряду одинаковая, 4 в ряд при ширине ≥ 880 px, иначе 2×2.

### График

| Элемент | Значение |
|---|---|
| Заголовок (вывод) | 15–16 px, 600, #1D1D1B |
| Подзаголовок (единицы, период) | 13 px, 400, #6B6B76 |
| Подписи осей и тиков | 12 px, 400, #6B6B76, tabular-nums, без поворота |
| Прямые подписи значений | 12–13 px, 600, цвет серии или #1D1D1B |
| Аннотации | 12 px, 400 italic или с выноской-линией, #5B5B66 |
| Сетка | только горизонтальная, 1 px #EEEEF2, 4 линии; ось Y начинается с 0 для баров |
| Линия | 2 px, акцент; контекст и сравнение 1.5 px серым или пунктиром |
| Бар | высота 16–20 px, промежуток 8 px, radius 2, один цвет |
| Высота графика | основной 260–320 px, в колонке 200–240 px |
| Тики X | максимум 6–8 подписей, формат `янв 17` |
| Tooltip | 13 px, «Ноя 2017 · Выручка 1,18 млн R$ · ▲ 53 % м/м» |

Цвета: акцент `--brand` для основной серии; серые `#B8B8C2` для контекста и `#EEEEF2` для сетки; статусы: «хорошо» `#1F9D55`, «плохо» `#D64545`, «внимание» `#C98A00` (только для Δ и порогов).
