# Визуальный бенчмарк дашборда Datum

Продолжение `docs/dashboard-readability.md`. Там описано, что показывать. Здесь описано, как это нарисовать: конкретные размеры, цвета и компоненты.

Метки достоверности:
- **[src]** — значения взяты из исходников компонента.
- **[ref]** — значения сняты с продукта как ориентир, исходники не проверялись.

### Правила использования токенов

- **Цвет.**
  - Акцентный цвет один: `--chart-accent`. Сравнение даётся серым пунктиром.
  - Красный и зелёный используются только для дельт и «плохих» строк, а не для категорий.
  - Многосерийность нужна редко: максимум 2 серии на одном графике.
- **Числа.**
  - `font-variant-numeric: tabular-nums` для всех числовых элементов.
  - Формат `ru-RU`; «млн» и «тыс.» только в KPI и тиках, в таблицах полные числа.
  - Валюта R$ ставится в подзаголовке графика, а не в каждом тике.
- **Подписи.**
  - На бар-чартах значения пишутся прямо на барах (LabelList, 12px/600), ось Y тогда скрыта.
  - На линиях последнюю точку подписывать прямо, а не легендой.
- **Тултип.** Шапка с датой «авг 2018», затем строки: свотч 8px, название, значение справа. Отдельной строкой «к пред. месяцу» с pill-дельтой.
- **Скелетон.**
  - KPI: строка метки 12×80px, значение 28×120px, спарклайн 36px на всю ширину.
  - График: 4 горизонтальные полосы-сетки и блок 60% высоты.
  - Бар-лист: 5 строк по 32px с шириной 90/70/55/40/30%.
- **Движение.**
  - Area и линия: `animationDuration 700ms`, `ease-out`, только на mount.
  - Бар-лист: `transition: width 400ms var(--ease-out)`, stagger 30ms.
  - Tween значения KPI 350ms при смене фильтра.
